# Payroll Reconciliation & Manpower Cost Analysis

## Project Overview

This project simulates a monthly payroll reconciliation process for a fictional manufacturing company using Microsoft Excel.

The project focuses on comparing current-month payroll with prior-month payroll, identifying payroll variances and exceptions, and summarizing manpower costs by department.

All employee data and payroll assumptions used in this project are fictional and created for learning and portfolio purposes.

## Project Objectives

- Calculate current-month payroll using employee master and attendance data
- Compare current payroll with prior-month payroll
- Analyze payroll variance and variance percentage
- Identify payroll exceptions that require further review
- Summarize payroll costs and overtime by department
- Practice payroll control and reconciliation using Excel

## Payroll Exception Checks

The project uses simplified payroll control rules to identify records that may require further review.

Examples include:

- Employee status is not Active
- Approved overtime hours exceed the defined exercise threshold
- Payroll variance exceeds the defined exercise threshold

An exception does not automatically mean that the payroll data is incorrect. It indicates that the record should be reviewed and verified before payroll approval.

## Key Learning

This project helped me understand that payroll analysis is not only about calculating employee pay.

A payroll analyst should also:

- Verify employee and attendance data
- Compare payroll with prior periods
- Investigate unusual payroll changes
- Review payroll exceptions before approval
- Check supporting data before making conclusions
- Maintain payroll data accuracy and confidentiality

## Workbook Structure

- `Employee_Master` — employee master data
- `Attendance_Current` — current-month attendance and overtime data
- `Prior_Month_Payroll` — payroll reference from the previous month
- `Payroll_Reconciliation` — current payroll calculation and reconciliation
- `Manpower_Cost_Summary` — department-level payroll and manpower cost summary

## Disclaimer

This project is a simulated learning project.
